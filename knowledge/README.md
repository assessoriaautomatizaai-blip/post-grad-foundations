# knowledge

Base de conhecimento do agente: **um trecho por dispositivo legal** (EC 132/2023 e LC 214/2025), em JSON versionado.

Cada trecho tem `id` estável, `norma`, `dispositivo`, `texto`, `url_fonte` (Planalto) e `data_referencia`, e só entra depois de conferido pelo autor no texto oficial. Ver ADR-005 em [docs/decisoes.md](../docs/decisoes.md).
